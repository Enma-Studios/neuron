**Default engines.** Google is bot-walled on Browser Use cloud addresses on every query,
seven of seven in the #43 acceptance run and four of four in the diagnostic. It stays fully
supported and ships switched off, with its moduledoc recording why and that a local browser
provider may be an address it serves results to, which is `neuron-02`. `docs/configuration.md`
now names all four switched-off engines with the specific reason each one needs.

Fixing this surfaced a second problem worth naming: the application config and the compiled
`@default_engines` fallback had disagreed since Reddit was removed, so the engine set depended
on whether config had been loaded. A host does not load a dependency's config, which is
neureni#37's whole subject. They now agree and a test asserts both, alongside the invariant
that no engine needing a login or failing a bot check is ever on by default.

**Dgraph conflict retry.** Six ingestion children in the #43 acceptance run failed with gRPC
status 10 carrying Dgraph's own `Transaction has been aborted. Please retry`, and nothing
retried. The run survived; the evidence those children had gathered did not. Aborts are now
retried with bounded exponential backoff across all three write paths, since `upsert/2`,
`insert_once/2` and `replace/3` each call `Dlex.mutate` and each had the identical gap. Only
aborts are retried. A conflict that exhausts its retries is counted against the run and
surfaces as `usage.total.graph_conflicts`, aggregating a campaign's ingestion children into
the parent, so a run that lost evidence says so instead of looking clean.

**The listing note, corrected.** Both the #44 handoff and the v0.2.0 handoff said the Browser
Use listing parameter is `pageSize`. The full truth is that it pages on **`pageSize` and
`pageNumber`**, reports `totalItems`, and ignores `limit`, and it is `limit` being ignored
that makes the endpoint look like it truncates to ten rows. The code already did the right
thing; the prose named half of it. Corrected in both handoffs, with the consequence for
neureni#40 spelled out: a cost poll that passes `limit` undercounts.
