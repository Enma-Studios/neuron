# Handoff: neuron 2026-09-12

Cumulative, v0.2.0 through v0.2.8. Written to be read cold.

## Context

Neuron went from `v0.2.0` to `v0.2.8` between 2026-09-10 and 2026-09-12, nine tags in three
days, starting from the findings the Neureni spike recorded on 2026-09-10 (neureni#43, #44,
#38, #41, #40, #42) and continuing into defects found by live runs rather than by reading code.
This handoff covers the whole window: what each release changed and why, what was proven
against a live service versus a fixture, what is open by number, and what a host now depends
on. The per-release handoffs in this directory stay authoritative for detail; this one is the
map.

## What changed

Oldest first. Every line is a merged PR in `Enma-Studios/neuron` unless marked otherwise.

**v0.2.0** — 2026-09-10, `2673d0e`. Before it, a run against Enma's real brief on the engine
configuration the host must use ingested nothing at all. After it, the same brief and
configuration ingested real prospect companies. ([handoff](2026-09-10-v0.2.0.md))

```
a2ac788 stop every Browser Use session on cancel, crash, and shutdown (Refs neureni#44)
5a78bf0 make walled engines visible so public discovery finds prospects (Refs neureni#43)
17c9e29 resolve the embedding model path through one function (Refs neureni#38)
7a4c15a classify skipped engines so a host can tell degraded from unavailable (Refs neureni#41)
60b9e76 report usage and an error class on the run snapshot (Refs neureni#8, #40)
3ee623a return leads without an observed contact channel on request (Refs neureni#42)
```

Why: billed cloud browsers outlived their owners; bot walls read as honest emptiness, so
`orchestrate/2` never called `blocked?/1`; the model fetch wrote where the loader does not
read; a host had no way to tell a degraded round from an unavailable search; no usage was
recorded anywhere; and Neuron discarded exactly the leads the host exists to complete.

**v0.2.1** — 2026-09-10, `d3fe71d`. ([handoff](2026-09-10-v0.2.1.md))

## Contract and prototype notes

No prototype in this repository; it is a library. Contract changes a host sees, all additive
except the first:

- `get_run/1` no longer reconciles. `reconcile_run/1` returns the same snapshot and something
  has to call it — on a schedule, or on a run that has not advanced for longer than its longest
  legitimate stage. This is the one behavioural change a host must act on.
- `usage` is always on the run snapshot; `error_class` appears only when the run carries an
  error, with `:budget` reserved and never raised.
- Failure entries carry `{kind, reason}` with `:login_gate`, `:consent_wall`, `:bot_check`,
  `:page_failed`, `:harvest_failed`. A completed run with failures is degraded; a failed run
  with `:search_unavailable` means search was unavailable.
- `require_contact_channel: false` returns matched people with `observed_email: nil`, and the
  summary distinguishes "no companies matched" from "matched, no contact channel observed".
- Intake's `scrape_error` is `{step, reason}` over `:fetch`, `:html`, `:normalize`,
  `:save_document`, `:prompt`, `:model`, `:decode`. Only `:fetch` blames the URL.
  `:url_unavailable` is gone.
- A scraped campaign carries `source_markdown`, `source_url` and `field_sources`. Summaries are
  unchanged; the excerpt is additional.
- `BRAVE_SEARCH_API_KEY` is optional. Without it Brave is absent from the round rather than
  failing in it.

## Decisions

- **A published tag is never moved.** Learned by breaking it on `v0.2.3`. `v0.2.4` reports
  `0.2.3` in `mix.exs` permanently rather than being corrected. `mix neuron.release.check TAG`
  now fails a release whose declared version disagrees with the tag being cut, and passes
  quietly when `HEAD` carries no tag, so it is safe in CI on every commit.
- **Git dependencies are pinned to tags, not branches**, for the same reason one layer down.
- **Default engines are DuckDuckGo and Yandex.** Google, LinkedIn, X and Reddit ship switched
  off, each with the reason in `docs/configuration.md`. No engine that needs a login or fails a
  bot check is ever on by default, and a test asserts it.
- **A keyed engine without a key is absent from the round, not failing in it**, because an
  engine nobody asked cannot be evidence that search is unavailable.
- **No prices and no cost cap.** Tokens and seconds are counted, not converted to money; a rate
  table in library code is a decision, not an implementation detail. `error_class` reserves
  `:budget` against the day there is one.
- **`email` is not renamed.** `observed_email` sits alongside it until `neuron-06`.
- **An excerpt is the page's bytes.** Whitespace-only drift is relocated and re-sliced from the
  Markdown; anything not on the page is dropped rather than returned as evidence. One step more
  forgiving than `Knowledge.validate_claims/2`, never less exact about what it returns.
- Recorded in a commit body and worth carrying: `source_markdown` rides the campaign map and is
  re-serialized at every stage checkpoint. Marked `ponytail:` at the assignment.
