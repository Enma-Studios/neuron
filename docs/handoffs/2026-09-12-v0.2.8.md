# Handoff: v0.2.8

One change: intake now shows its work.

| PR | Change |
| --- | --- |
| [#32](https://github.com/Enma-Studios/neuron/pull/32) | Return the excerpt each scraped field came from, and the page |

**A summary with nothing behind it.** Intake returned `field` and `offer` as the model's
sentences, and a host reading them had no way to see what on the page produced them short of
reading Dgraph. Each scraped key now carries `%{excerpt:, source_url:}` in `field_sources`, and
the campaign carries the cleaned Markdown once as `source_markdown` alongside `source_url`, so a
host that never reads Dgraph can retain the page the excerpts point into. The summaries are
unchanged; the excerpt is additional.

**The excerpt is the page's bytes, not the model's rendering of them.** Every quote comes back
anchored into the Markdown and re-sliced from it. A quote that differs only in whitespace is
relocated: nyx-labs.org sets its headings in U+00A0, and a model quoting them types ordinary
spaces, so a literal `String.contains?` would have dropped the offer excerpt on the very page
this was filed for. A quote that is nowhere on the page is dropped rather than shipped as
evidence for a sentence nobody wrote. This is the rule `Neuron.Knowledge.validate_claims/2`
already applies to claims, one step more forgiving about whitespace and never less exact about
what it returns.
