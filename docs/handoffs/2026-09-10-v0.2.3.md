# Handoff: v0.2.3

Both defects the layered-context experiment found in the search and graph paths, fixed.

| PR | Change | Issue |
| --- | --- | --- |
| [#14](https://github.com/Enma-Studios/neuron/pull/14) | Balance a round across enabled engines and count only engines tried | neureni#72 |
| [#15](https://github.com/Enma-Studios/neuron/pull/15) | Write the source edge on every ingested assertion | neureni#73 |

**Engine coverage.** Four of ten experiment runs failed identically: the planner put every
query of the round on DuckDuckGo, DuckDuckGo bot-checked all of them, so every *attempted*
engine had failed and the round was declared unavailable while Yandex sat enabled, healthy and
unasked. `Neuron.Search.balance/2` now gives every enabled engine at least one query by
re-targeting from whichever engine the planner crowded, never by adding queries, so the round
stays inside `searches_per_round`. It runs after truncation, because balanced before it the
coverage queries are exactly the ones the budget drops. A round is unavailable only when every
enabled engine was actually attempted and failed.

**Source edges.** Ten runs produced 319 assertions and not one source edge, so a claim could
not be traced to the document it was read from. The schema was never at fault: the predicate is
declared and indexed, and `Neuron.Research` already wrote it. `Neuron.Knowledge.ingest/4`, the
path every campaign uses, had simply omitted it. One line, no migration.

## On how these were found

Neither came from reading the code. Both came from running it, as did the `v0.2.2` crash and
neureni#43 before that. Four defects in three days, all found by live runs and none by the test
suite, is the pattern worth noticing here.

Every fix in this release was confirmed load-bearing by reverting it and watching the new test
fail, rather than by asserting that it must be.

## Verification

110 tests passed, 3 excluded, plus 2 Dgraph integration tests against v25.4.1.
`mix format --check-formatted` clean. No live campaign runs were needed, so nothing was spent.
