# Handoff: v0.2.2

A single-defect patch release.

| PR | Change | Origin |
| --- | --- | --- |
| [#12](https://github.com/Enma-Studios/neuron/pull/12) | A candidate with no name or employer must not crash selection | layered-context experiment |

`neuron-12` split "does this person match the campaign" from "can we reach them" and moved the
check out of `if valid do` into `cond do not matched ->`. The match chain is a `&&` chain that
returns `nil` rather than `false` when it short-circuits on a missing name or a missing
employment claim. `if` accepts `nil`; `not` demands a boolean and raises.

A live run failed this way after ingesting 47 claims from 7 organizations, and discarded all of
it. `require_contact_channel: false` makes it much more likely, because candidates that used to
be filtered out before reaching the scoring branch now reach it.

The fix is `!matched`. The regression test covers a nameless and an unemployed record under the
option both ways, and was confirmed to fail with the original `ArgumentError` when the fix is
reverted.

It was found by running the layered-context experiment rather than by reading the code, which
is the second time in two days that a live run has found something no test did. The first was
neureni#43.

## Verification

105 tests passed, 3 excluded. `mix format --check-formatted` clean. No live runs were needed
for the release, so nothing was spent on it.
